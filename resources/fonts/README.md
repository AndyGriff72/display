# Bundled fonts

## Bedstead (`bedstead.otf`)

A recreation of the character set of the Mullard SAA5050, the chip that drew Teletext
(Ceefax, Oracle) on British televisions. Version 3.261, by Ben Harris:
<https://bjh21.me.uk/bedstead/>.

Licence, as the author states it: the program that generates Bedstead and all of its newly
designed glyphs are released into the public domain; he believes the original SAA5050 bitmap
font is "essentially in the public domain in the United Kingdom", while noting he is not a
lawyer. Bundled on that basis: UK protection for a typeface used commercially lasts 25 years,
long past for a 1980 chip, and bitmap character shapes are generally not protected as typefaces
in the US.
